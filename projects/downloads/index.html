怎么装到眼镜上？

  1. 在手机或电脑上下载 APK；商店页面需按其提示下载。
  2. 将 APK 传到眼镜内，用文件管理器打开。若系统提示，按需允许该文件管理器安装未知应用，装完可关闭权限。
  3. 也可用电脑通过 USB 连接并授权调试，运行 adb install 文件名.apk。

页面里的版本是记录版本，商店和非固定链接可能更新。标为「真机体验」的是报告中做过的操作；标为「已安装」的应用还没有逐项测试。
