# INMO · 进入空间时代

[在线游玩](https://inmo-ar-stealth-game.netlify.app)

第一幕已重做为独立的新品发布会潜入挑战。场景参考用户提供的「11.04 影目新品发布会」海报，以金橙色、黑铜舞台与悬浮立方体构成室外发布广场和店内新品体验区。旧警局、押送和公路追逐不再加载，也没有继续故事的入口；被发现后仅重新开始。

## 场景与目标

- 店内发布主屏、样机展台、体验区、媒体和观众席。
- 室外签到区、暖场舞台及 4 位成年女舞者循环舞蹈。
- 40 位观众/工作人员，分组看样机、看演出、拍照、鼓掌和玩手机。
- 24 句轮换幽默气泡，同屏最多 3 个；掌声音效跟随静音设置。
- 目标是主舞台的「INMO 神秘新品」样机，只需要取走这一副。
- 新品型号、售价、正式外观未在本项目中核实；模型与缩略图明确标注为游戏概念造型。5000 是游戏任务积分，不是人民币价格。

## 不同的行动路线

| 方法 | 条件与代价 | 效果 |
|---|---|---|
| 徒手取镜 | 展台 2.65 米内，3.4 秒 | 保持不动完成回收 |
| 伸缩钩 | 6.2 米内，4.6 秒，仅一次 | 显示钩线；摄像头和人群也会注意样机位置 |
| 瞌睡汽水 | 到饮料台，一次 | 纯虚构游戏道具，让两名巡场安保暂时休息 16 秒 |
| 服务员帮忙 | 走近服务员，250 游戏筹码 | 引开安保 12 秒；每局共 500 筹码 |
| 舞台应援 | 到应援控制台，一次 | 让人群转向暖场舞台 7 秒 |

正常走动不会被抓；回收样机期间被摄像头、安保或近处观众看到，本局结束。玩手机、看表演和道具影响实际观察判定，摄像头不受道具影响。人群每轮有可见的注意力空窗，玩家要结合扫描时机。

## 操作

- WASD / 方向键按屏幕方向行走；点击地面会绕开家具、观众席等障碍。
- 点击主展台或目标清单导航，走近后按 E / 空格取镜。
- 右上「行动道具」展开库存；距离不够时第一次点击会导航，走近后再次点击使用。
- Shift / C 蹲姿慢走，Esc / P 暂停，R 重开，M 音效，V 重置视角。
- 右键拖动可小幅转向，鼠标滚轮不缩放。
- 失败只可重来；成功自动保存当前浏览器发布会榜单，和旧版六柜台榜单隔离。

## 本地运行与交付

需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm run dev
```

开发服务器提供构建后的 dist，修改后重新构建。构建同时生成 release/inmo_launch_event.html 和兼容文件名 release/inmo_3d_ar_optimized.html，内嵌 Three.js、场景、道具和样式，可离线打开。新版入口不加载旧章节的物理引擎或素材。

核心文件：index.html（回收、失败、榜单及输入）、launch-venue.js（场景、人群、表演、注意力）、launch-tools.js（库存与交互）、launch-event.css（发布会 HUD）、showroom-assets.js（概念眼镜模型）、game-rules.js（视线与寻路）。

Netlify 使用 netlify.toml：npm run build，发布 dist。旧章节源码与旧价格/图片素材留作项目历史，没有接入当前玩法。现存 tests 是旧玩法的历史检查，不代表发布会新机制已经通过自动化测试；本轮未增加或运行测试。
