# INMO · 好戏开场

Three.js 第一人称发布会互动喜剧。以用户提供的影目展会照片为舞台背景；人物和剧情为虚构群友演绎，非官方活动实录。

## 观看

默认第一人称观众席，点击“入座 · 开始演出”解锁声音。全场约4分钟：小影感谢AIR3用户群、云飞诗朗诵、小仓鼠跳绳、韦爵爷单口相声、终场停电与日期反转。底部字幕自动播放，可按空格或点“下一句”。可鼓掌、大笑或起哄。

- WASD/方向键：沿中央过道、前后横过道移动
- 拖动画面转头；移动端左侧虚拟方向键、右侧滑动控制视角
- F / 顶部视角按钮：第一人称、第三人称跟随、俯视循环切换
- P/Esc：暂停；设置里可回座、重播、开关浏览器中文语音
- 音乐独立开关，使用用户提供的MP3循环播放

## 开发

Node >=20。npm install 后 npm run build 生成 dist/；npm run dev 在4173端口提供构建产物。npm test 检查演出时间轴状态边界。

新入口只加载 theater-show.js（剧情状态）、theater-scene.js（场景）、theater-models.js（素材适配）、theater-app.js（输入、演出姿势、声音与字幕）。旧潜行/追逐源文件保存在Git历史与工作目录，不加载或发布。构建先仅清理工作目录内的生成目录dist，发布本地Three r128及模型，无在线CDN依赖。

release/inmo_launch_event.html 和 release/inmo_3d_ar_optimized.html 是内嵌音乐、照片、模型、依赖的离线单文件。

模型来源及许可详见 assets/theater-models/LICENSES.md。原始品牌展台照片由用户提供。

谢幕后自动进入四人64秒循环breaking返场舞，观众持续鼓掌欢呼，舞台暖金/粉紫灯束缓慢交替。设置中“直接看谢幕舞”可跳到返场；可暂停、切换视角、自由走动、重看或离场。

返场包含齐舞与四位轮流SOLO，编排站立步法、下地衔接、地板脚步、扫腿、支撑定格与起身。底部显示当前舞段和领舞者，“换一段”可跳至下个8秒舞段。
