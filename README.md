# INMO 潜行行动

Three.js 45° 俯视潜行小游戏。玩家从街道进入半剖面的 INMO 展厅，在红色摄像头扇形视野和店员黄色视线之间寻找时机，取走六个柜台上的眼镜。

[在线游玩](https://inmo-ar-stealth-game.netlify.app) · [GitHub 源码](https://github.com/elfwind724/inmo-ar-stealth-game)

## 场景与眼镜素材

展厅使用深色石材、金属展柜、分柜聚光、环境反射和柔和投影。六副眼镜拥有独立镜框轮廓、镜片、镜腿、鼻托和传感器细节；场景模型为游戏展示而制作，并非原厂 CAD 模型。走近柜台可查看对应的产品展示图，图鉴中也保留了产品图。

产品图片来自 [INMO Air 发布报道](https://www.leiphone.com/category/industrynews/0d1ucsnmAHQrTqtO.html)、[官方支持中心](https://support.inmoxr.com/) 与 [GO3 官方产品页](https://www.inmo.com/products/inmo-go3)，原图地址记录于 `assets/products/sources.json`。图片与品牌权利属于各自权利人。

## 操作

- `WASD` / 方向键：按画面方向移动；触屏设备显示方向按钮
- 点击地面：绕开柜台、墙面和绿植，走到目标位置
- 点击柜台或展开清单后点击型号：自动走近，抵达后手动选择取镜
- `Shift` / `C`：切换蹲姿慢走，方便微调位置
- `E` / 空格，或点击近处柜台的“取走眼镜”：开始约 1.4 秒的取镜动作；移动可中断
- `Esc` / `P`：暂停、继续，或关闭当前说明/榜单
- `R`：重新开始；`M`：音效开关；`V`：重置视角
- 按住鼠标右键拖动：轻微旋转观察方向
- 鼠标滚轮不会缩放画面

进入视线本身会发出警示；正在取镜时被摄像头或店员看到会被抓获，包括取镜完成的最后一帧。店员巡看六个柜台，偶尔玩手机，此时黄色视线消失。取完六副即可通关，通关成绩自动保存到本机前十榜单，可修改代号，同一局不会重复入榜。得分为人民币参考总价加潜行与速度奖励。排行榜保存在当前浏览器中，不跨设备同步。

清单和地图默认收起，可点击展开。价格参考、排行榜和帮助窗口会暂停计时与巡逻；切走窗口时也会暂停并清除移动按键状态，返回后手动继续。

## 隐藏第二章：警局突围

被抓后可选择「重来」或「继续」。继续会播放双警员押送、上警车、警车驶离与黑屏转场，随后进入半剖面的警察局拘留室。

送饭警察靠近后会说「吃饭吧，垃圾小偷」。点击他、按 E 或点「打晕警察 · 拿钥匙」，角色会自动靠近并反击，拿到钥匙后牢门打开。送饭警察属于剧情角色，后续另有 7 名警卫和 1 名典狱长 Boss。

- 点击敌人 / F / 迎战按钮：自动追近，刺拳、直拳、摆拳、回旋飞踢四段连击；击倒后继续迎战附近敌人
- 点击地面 / WASD / 方向键 / 触屏方向按钮：移动走位
- 空格 / Shift / 右下角按钮：闪避，冷却 1.5 秒
- 出拘留室后，2～3 名警卫会主动从不同方向包围、举棍、攻击；其他警卫在队友倒下后补位
- 红色范围：警卫即将挥棍；橙色范围：Boss 举棍重击、横扫或冲刺
- 玩家和警卫都有受击硬直、击退、发光反馈；命中带短暂停顿、震屏、拳脚轨迹、冲击闪光及伤害数字
- 普通警卫有短暂的抗连续硬直时间，Boss 连续受击会积累破防，无法一直被普通拳打断出招
- 击倒普通警卫恢复 9 点体力；Boss 登场时恢复 35 点体力
- Esc / P：暂停；失败后可直接重试警局，也可返回展厅

击倒全部 7 名警卫与 Boss 后显示「逃出警察局成功」，随后自动进入第三章，也可点击「开走警车」立即进入。原有本机排行榜继续记录展厅六副眼镜通关成绩。

## 第三章：夜间警车追逐

[直接试玩第三章](https://inmo-ar-stealth-game.netlify.app/#chase)。主故事仍按展厅、警局、公路的顺序推进；此链接提供独立的第三章入口。

第三人称跟车视角，夜间城市快速路，车顶显示实时耐久。使用 [Rapier](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/) 的动态刚体、连续碰撞检测和碰撞事件处理车辆互撞与护栏碰撞。

- A / D 或左右方向键：转向；S / 下方向键：刹车；W / 上方向键：加速
- 无碰撞时自动提速，玩家最高 230 km/h，追击警车动力最高 190 km/h
- 碰撞会降低车速和耐久；耐久归零或被撞停连续 3 秒失败
- 空格：急刹反撞，短时间内用车尾撞击后方警车可使其失控，冷却 3.4 秒
- C / 看后方按钮：切换后视；触屏提供转向、刹车、反撞按钮
- 警车会跟车、分侧包夹、预警后冲撞；持续出现前方并线增援，损坏车辆会失控退出追击
- 坚持 120 秒即成功逃脱；失败后可直接重试第三章
- Esc / P：暂停；切出窗口会暂停并清空操作状态

## 本地运行与部署

需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。开发服务器提供构建后的 `dist/`，修改源码后重新运行构建并刷新页面。

构建同时生成 `release/inmo_3d_ar_optimized.html`，是内嵌了运行依赖的单文件版本，可直接双击用浏览器打开，方便本地游玩和拷贝。首次下载源码仍需先构建。

源码入口为 `index.html`，规则与寻路在 `game-rules.js`，界面补充样式在 `ui-polish.css`；第二章在 `police-chapter.js` / `.css`，第三章在 `highway-chase.js` / `.css`。`physics-bridge.js` 由 esbuild 打包 Rapier 的兼容版，WASM 内嵌。构建将所有运行依赖放入 `dist/`，发布后不依赖第三方 CDN。单文件版也内嵌了三个章节及物理引擎；价格来源链接需联网访问。第三方许可说明保留在 `dist/vendor/`。

Netlify 已在 `netlify.toml` 配置：构建命令 `npm run build`，发布目录 `dist`。上传源码仓库后可直接接入持续部署，也可手动上传 `dist/`。原始下载文件保持不变。

## 已有自动检查

`npm test` 检查真实地图的六柜台寻路、柜台与店员碰撞、视野边界、取镜判负优先级、屏幕方向移动、场景初始化、暂停、重开与本机成绩保存。运行流程检查采用模拟 WebGL 渲染器，不能替代浏览器中的实际画面和设备性能验证。
