# INMO · 发布会里的钥匙

[在线游玩](https://inmo-ar-stealth-game.netlify.app)

金橙色新品发布会场景，包含室外暖场演出、店内样机展柜、媒体与观众。玩法已简化为单场景的钥匙谜题和潜入挑战：与 NPC 交谈取得线索，查看场景物件寻找钥匙，使用钥匙打开样机柜，再取回眼镜。失败只重新开始，没有押送、警局或追逐关卡。

## 本轮调整

- 玩家模型缩至原来的 86%，选中环和接地阴影同步收小；蹲姿和重开不会恢复旧尺寸。
- 去除伸缩钩、饮料、筹码和应援等主动道具与库存。
- 两位线索 NPC 以小问号标识，可点击走近、按 E 交谈；关键物件可点击走近查看。
- 开柜约 1.5 秒，取镜约 1 秒；玩家移动可取消当前动作，已拿到的钥匙、已打开的柜门保留到本局结束。
- 正常走动和交谈不会失败。只有开柜/取镜期间被持续注意约 1.2 秒才会被抓，中间有警觉提示并可走开。
- 安保独立巡场、转头或看手机，观众照常看表演、拍照、聊天；取消全体固定时刻同步停止观察的设计。
- 保留室外 4 位成年女舞者与 42 人现场，新增 inmo小影、小mo、韦爵爷、周云飞的常驻名牌与循环演出，重要剧情台词优先显示。

具体谜题答案和攻略不写入游戏界面或本文档。新品正式型号、价格和外观尚未在本项目中核实，模型标注为原创游戏概念造型；任务积分不是人民币价格。

## 入场与人物演出

首次进入播放黑金大厅、橙金高门与玩家缓缓入门的独立开场，末段黑屏切入发布会；可以跳过，失败重来不重复播放，暂停菜单可重看。开场按 P 暂停，空格或 Esc 跳过。

女司仪 inmo小影拿麦宣传；舞者小mo显示原创宣传歌词；主播周云飞持自拍杆轮播口播；韦爵爷在室外舞台边起哄，专用秩序保安将其拦住，28 秒循环复位。事件不移动柜台巡场安保，也不改钥匙线索角色。台词均为游戏原创，未加入新品型号、具体参数或价格。

## 操作

WASD / 方向键按屏幕方向行走；点击地面、人物或物件走近。E / 空格进行附近交谈、查看、开柜或取镜；触屏显示对应交互按钮。Shift / C 蹲姿慢走，Esc / P 暂停，R 重开，M 音效，V 重置视角。右键可微调观察方向，滚轮不缩放。

成绩保存在当前浏览器的发布会榜单中。普通暂停或离开窗口会暂停现场并清空按键。

## 构建与发布

需要 Node.js 20+，执行 npm ci、npm run build、npm run dev。修改源码后重新构建，开发服务器提供 dist。

构建生成 release/inmo_launch_event.html 与兼容文件名 release/inmo_3d_ar_optimized.html，内嵌运行依赖，可离线打开。当前入口只加载 Three.js、场景、谜题与界面，不加载旧章节和主动道具。

主要文件：index.html（输入、开柜/取镜、警觉及结果），launch-venue.js（现场、人群与演出），launch-puzzle.js（钥匙、NPC 线索和物件交互），launch-intro.js（独立开场），launch-event.css（界面），showroom-assets.js（概念模型），game-rules.js（寻路与视线）。Netlify 构建命令 npm run build，发布目录 dist。历史章节、旧道具与旧测试保留为历史文件，未接入当前玩法；本轮未增加或运行测试。
