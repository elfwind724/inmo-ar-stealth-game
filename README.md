# INMO · 发布会里的钥匙与追逐

[在线游玩](https://yiage.vip/)

新品发布会场景，包含室外暖场演出、店内样机展柜、媒体与观众。主展区按用户提供的展台照片调整为白色展墙、黄橙色斜光、黄色地毯、黑色桌布和金属眼镜支架。第一关通过交谈、找钥匙和躲开视线取得样机；小影随后冲下舞台喊“抓小偷呀！”，追着玩家跑出展厅，黑屏进入第二关的三分钟纵版追逐。

## 本轮调整

- 玩家模型缩至原来的 86%，选中环和接地阴影同步收小；蹲姿和重开不会恢复旧尺寸。
- 去除伸缩钩、饮料、筹码和应援等主动道具与库存。
- 两位线索 NPC 以小问号标识，可点击走近、按 E 交谈；关键物件可点击走近查看。
- 开柜约 1.5 秒，取镜约 1 秒；玩家移动可取消当前动作，已拿到的钥匙、已打开的柜门保留到本局结束。
- 正常走动和交谈不会失败。只有开柜/取镜期间被持续注意约 1.2 秒才会被抓，中间有警觉提示并可走开。
- 安保独立巡场、转头或看手机，观众照常看表演、拍照、聊天；取消全体固定时刻同步停止观察的设计。
- 保留室外 4 位成年女舞者与 42 人现场，新增 inmo小影、小mo、韦爵爷、周云飞的常驻名牌与循环演出，重要剧情台词优先显示。

具体谜题答案和攻略不写入游戏界面或本文档。新品正式型号、价格和外观尚未在本项目中核实，模型标注为原创游戏概念造型；任务积分不是人民币价格。

展墙与小立牌使用用户提供的两张展台照片作为画面参考，眼镜模型按照片调整黑框/象牙白框配色；这些游戏模型不代表正式产品的精确尺寸或参数。

## 入场与人物演出

首次进入播放黑金大厅、橙金高门与玩家缓缓入门的独立开场，末段黑屏切入发布会；可以跳过，失败重来不重复播放，暂停菜单可重看。开场按 P 暂停，空格或 Esc 跳过。

女司仪 inmo小影拿麦宣传；舞者小mo显示原创宣传歌词；主播周云飞持自拍杆轮播口播；韦爵爷在室外舞台边起哄，专用秩序保安将其拦住，28 秒循环复位。事件不移动柜台巡场安保，也不改钥匙线索角色。台词均为游戏原创，未加入新品型号、具体参数或价格。

对白显示在姓名上层；发言人的名字合并进气泡，相邻气泡会避让，避免台词被姓名遮住。会场循环播放用户提供的《미래의 런웨이》，右上角「♫」按钮独立控制背景音乐并记住选择，原音效开关独立保留。首次点击或按键后允许播放，开场与后台页面暂停音乐；音乐文件也会内嵌进离线版。

周云飞和 inmo小影新增对话图标，点击可走近，靠近按 E 后依次显示玩家提问与人物回答。可以向周云飞求签名、问小影几点下班；交谈会暂时让出该角色的宣传台词，结束后恢复现场演出，不影响钥匙谜题。

## 操作

地图旁的视角按钮或 F 可切换 45° 俯视与第一人称。WASD / 方向键：俯视按屏幕方向，第一人称按镜头方向前后左右移动；点击地面、人物或物件走近。E / 空格进行附近交谈、查看、开柜或取镜。Shift / C 蹲姿慢走，Esc / P 暂停，R 重开，M 音效，V 重置当前视角。第一人称按住鼠标右键拖动观察，俯视右键微调，滚轮不缩放。

移动端保留左侧虚拟方向键，第一人称可右手在画面右侧拖动观察，与左手移动同时使用；轻点与拖动分开处理，避免转头时误触寻路。第一人称点击会检查可见物体遮挡，地面导航限近处。

## 第二关：追逐

取镜后玩家会沿可走路线自动跑向门外，仍可用方向键调整；小影沿同一套寻路规则追赶。真正穿出入口后才切换关卡。

追逐采用纵向 3D 街道画面。鼠标连续点击、手指轻点画面或反复按空格加速；长按不连发。小影恒速 80 码，玩家起速 86 码、逐渐减速，每点一次增加 4.8 码、最高 128 码。低于 80 码持续一段时间并被追近后，小影会腾空飞踢：每次仅结算一次 15% 生命损失，伴随冲击环、碎光、震屏和玩家前扑恢复。生命初始 100%，有效奔跑时间满 180 秒且仍有生命即可过关。

P / Esc 或追逐右上角按钮暂停，音乐独立开关保留；切后台冻结计时、速度和伤害。R 或结果页“重试追逐”直接重试本关，也可选择“重返发布会”。只有完成两关才自动保存成绩，奖励结合第一关表现、三分钟生存与剩余生命，榜单保存在当前浏览器。

## 构建与发布

需要 Node.js 20+，执行 npm ci、npm run build、npm run dev。修改源码后重新构建，开发服务器提供 dist。

构建生成 release/inmo_launch_event.html 与兼容文件名 release/inmo_3d_ar_optimized.html，内嵌运行依赖、图片、音乐及纵版追逐，可离线打开。

主要文件：index.html（输入、双关衔接、警觉及结果），launch-venue.js（现场、人群、演出与小影追出），launch-puzzle.js（钥匙、NPC 线索和物件交互），launch-intro.js（独立开场），chase-runner.js / chase-runner.css（第二关场景、速度、飞踢与血量），venue-music.js（背景音乐与播放偏好），launch-event.css（界面），showroom-assets.js（概念模型），game-rules.js（寻路与视线）。Netlify 构建命令 npm run build，发布目录 dist。历史章节、旧道具与旧测试保留为历史文件，未接入当前玩法；本轮通过构建、独立追逐机制校验和真实碰撞/寻路校验；机制检查使用模拟画布，不代表浏览器画面或手机真机操作已经验证。
